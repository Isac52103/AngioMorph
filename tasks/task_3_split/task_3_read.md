Техническое задание (ТЗ):
Написать функцию process_split(src: Path) -> tuple[pl.DataFrame, pl.DataFrame], которая принимает путь к JSON-файлу. Файл содержит единый массив, в котором смешаны два типа сущностей: пользователи (type: "user") и устройства (type: "device"). У них разный набор ключей.
Функция должна:

    Загрузить JSON.

    Разделить данные на два независимых polars.DataFrame: df_users и df_devices на основе поля type.

    Удалить столбец type из обоих датафреймов.

    Очистить датафреймы от столбцов, содержащих только значения null (которые появились из-за слияния ключей разных сущностей).

    Вернуть кортеж из двух таблиц: (df_users, df_devices).
