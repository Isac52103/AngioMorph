Техническое задание (ТЗ):
Написать функцию process_truncation(src: Path) -> pl.DataFrame, которая принимает путь к JSON-файлу. В файле содержится информация о кандидатах и массиве их навыков (skills). У одного из кандидатов массив skills значительно больше, чем у остальных. Функция должна загрузить данные в датафрейм и обрезать списки в столбце skills таким образом, чтобы в каждой строке оставалось не более 2-х первых навыков. Вернуть итоговый датафрейм.
