# YOLO Segmentation Evaluator

Модуль для автоматизированного тестирования и оценки качества моделей сегментации на базе Ultralytics YOLO.
Скрипт извлекает все основные метрики оценки (mAP, Precision, Recall), а также рассчитывает итоговый показатель F1-score.

## Структура проекта

```text
test_models_angiografia/
├── main.py                   # Исполняемый файл запуска процесса тестирования
├── configs/
│   └── test_config.yaml      # Конфигурационный файл параметров оценки и путей ввода/вывода.
├── data/                     # Корневая директория набора данных
│   ├── data.yaml             # Файл конфигурации датасета
│   ├── images/val/           # Директория тестовых изображений
│   └── labels/val/           # Директория файлов разметки полигонов в формате YOLO
├── models/
│   └── yolo26-seg.pt         # Файл весов обученной нейросетевой модели
├── results/                  # Директория сохранения выходных JSON-отчетов
└── requirements.txt          # Файл спецификации зависимостей окружения Python

```

## Системные требования и зависимости
Для функционирования модуля требуется интерпретатор Python версии 3.9 или выше. Инициализация программного окружения и установка зависимостей осуществляются командой:
`pip install -r requirements.txt`

## Конфигурация параметров оценки
Перед началом тестирования необходимо определить пути ввода-вывода в конфигурационных файлах:
* `data/data.yaml` — структура набора данных.
* `configs/test_config.yaml` — параметры процесса тестирования.

## Порядок эксплуатации
Запуск процесса автоматизированной оценки инициируется из корневой директории командой:
`python main.py`
Выходные данные (JSON-отчеты) будут автоматически сформированы в директории `results/`.
