# 📚 Практические задания (Polars & Инженерия данных)

Добро пожаловать в автоматизированную систему проверки домашних заданий! 
В этом репозитории вам предстоит решать задачи по обработке данных с использованием библиотеки **Polars**. Каждое ваше решение будет автоматически проверяться на правильность логики (Pytest), качество кода (Ruff) и строгую типизацию (Pyrefly).

---

## 🚀 Как начать работу (Пайплайн студента)

Чтобы выполнить задания и сдать их на проверку, строго следуйте этой инструкции:

### Шаг 1: Форк репозитория
У вас нет прав на прямую запись в этот репозиторий. Чтобы работать с кодом:
1. Нажмите кнопку **Fork** в правом верхнем углу этой страницы.
2. Снимите галочку *«Copy the main branch only»* (чтобы скопировалась ветка с заданиями).
3. Нажмите **Create fork**. Теперь у вас есть личная копия проекта.

### Шаг 2: Клонирование и настройка окружения
Откройте терминал на вашем компьютере и выполните следующие команды:

```bash
# 1. Склонируйте ВАШ форк на локальный компьютер
git clone [https://github.com/ВАШ_НИК/AngioMorph.git](https://github.com/ВАШ_НИК/AngioMorph.git)

# 2. Перейдите в папку проекта
cd AngioMorph

# 3. Обязательно переключитесь на ветку с заданиями!
git checkout homeworks

# 4. Установите необходимые библиотеки (рекомендуется использовать виртуальное окружение)
pip install -r requirements.txt
